Exemplo apenas com HTML

Esta página mostra somente a estrutura do conteúdo. Não há CSS aplicando cor, espaçamento, alinhamento ou layout visual. É exatamente assim que qualquer página começa: como uma obra antes do acabamento.

O que você está vendo

O navegador aplica um estilo padrão mínimo para que a página seja legível, mas nenhum CSS externo foi carregado. A hierarquia está aqui. A estrutura está aqui. Só falta o acabamento.

Elementos presentes

  • Título principal (h1)
  • Títulos secundários (h2)
  • Parágrafos (p)
  • Lista não-ordenada (ul / li)
  • Botão (button)
  • Link (a)

Estrutura semântica da página

Mesmo sem CSS, cada elemento tem um significado definido pelo HTML: h1 é o título principal, p é um parágrafo, ul é uma lista. O navegador, os leitores de tela e os mecanismos de busca entendem essa estrutura independentemente da aparência.
